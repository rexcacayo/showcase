# Showcase

> **Versión actual: 1.0.0** (Blender 4.2 – 5.x) → instalar `version_1.0.0/dist/showcase-1.0.0.zip`

Complemento de Blender para **enseñar tus piezas**: vídeos y fotos de producto en un clic. Monta un estudio automático (fondo curvo infinito, tres luces y cámara encuadrada según el tamaño de la pieza) y graba un vídeo predefinido —giro 360, vitrina o detalle— en MP4 cuadrado, vertical u horizontal, con tu marca de agua.

La pieza no se toca: gira la cámara. Los ajustes de render de la escena se restauran al terminar.

## Familia de plugins

**Mesh Doctor → Print Scale → Thicken → Fit Tolerance → Base Support → BigPrint / MagSnap → Color Print Splitter → Showcase**

| Versión | Novedades |
|---|---|
| 1.0.0 | Primera versión: presets Giro 360, Vitrina y Detalle; formatos cuadrado, vertical y horizontal; fondo claro u oscuro; color de filamento; marca de agua; foto PNG. |
